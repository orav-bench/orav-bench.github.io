# ORAV project page

Source of <https://orav-bench.github.io/>, the project page of
*ORAV: Benchmarking Audio-Video Generation from Multimodal Contexts*.

- Paper: <https://arxiv.org/abs/2609.34843>
- Code: <https://github.com/Tencent-Hunyuan/ORAV-Bench>
- Benchmark: <https://huggingface.co/datasets/ORAV-Bench/ORAV-Bench>
- Artifacts: <https://huggingface.co/datasets/ORAV-Bench/ORAV-Bench-Artifacts>

The site is plain HTML, CSS and JavaScript with no build step. To preview it locally:

```sh
python3 -m http.server 8000
```

then open <http://localhost:8000/>.

The self-hosted fonts (Newsreader, Inter, JetBrains Mono) are licensed under the
SIL Open Font License 1.1; see `assets/fonts/OFL-*.txt`.
