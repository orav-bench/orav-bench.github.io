Overview

Resembling a reference is not the same as using it as instructed.

Audio-video generation from heterogeneous multimodal references requires both compositional control and a grounded understanding of context. Instructions specify how the references relate; the media supply the identities, dynamics, and sounds to be realized. ORAV asks whether a generator understands what each reference is meant to contribute, how visual, dynamic, and auditory factors compose into one event, and which incidental source content must be left behind.

To evaluate these open-ended outputs, a reference-aware pairwise protocol prepares visual and auditory evidence, compares the intended contribution of each reference, and checks every verdict in both presentation orders. On held-out instances it agrees with human judgments 85.46% of the time. Across five frontier systems, overall rankings conceal distinct strengths across reference compositions, and a recurring failure is to reproduce unintended source content in place of the requested result — while still closely resembling a reference.

Cases

Six instructions, five generators, one shared clock.

Each case pairs a real benchmark instruction with its image, video, and audio references. The five outputs play in sync, ordered by overall rank. Scrub, slow down, and choose whose soundtrack you hear.

Benchmark

Nine roles across three modalities, composed into thirty signatures.

Every instance pairs an English instruction with 2–10 references, each assigned a semantic role. Where prior benchmarks isolate appearance, dynamics, or audio, ORAV requires content, dynamics, and audio to be composed within a single event.

Evaluation

A judge that looks, listens, and checks itself.

Similarity scores and generic prompts cannot rank open-ended multi-reference generations. ORAV separates listening from looking, compares every reference in the context of the whole instruction, and keeps a verdict only when it survives a swap of presentation order.

  1. 01

    Look and listen, separately

    Candidate and reference clips become timestamped 8 fps panels with audio-energy timelines. A visually blind Listener (Gemini-3.1-Pro) transcribes speech, flags reused recordings, and describes the soundtrack.

  2. 02

    Compare each reference in context

    The pairwise Judge (GPT-6-Astra) checks what each reference was meant to contribute, and whether unrequested scenery, performers, or recordings leaked in, before forming one joint preference.

  3. 03

    Decide in order, then swap

    Verdicts follow usability, then task fulfillment, then general quality. Every pair is judged in both presentation orders; matching decisions are kept, and order conflicts count as a tie in the ranking.

Findings

What the references reveal.

Finding 1 · Composition

Overall rankings hide context-dependent reversals.

MiniMax-H3 ranks third overall (54.0%) yet leads speech (73.6%) and four of five speech compositions. Adding a motion reference flips the order: MiniMax-H3 leads Seedance-2.5 by 19.5 points in subject + speech and trails it by 19.8 points in subject + motion + speech.

Removing only the motion reference from those same instances, with subject, voice, and scene held fixed, moves the pair from 73.4% vs. 53.6% to 80.2% vs. 87.8%, reproducing the reversal under matched inputs.

Finding 2 · Usability

Reference substitution drives 95% of unusable outputs.

Failing generators rarely collapse into noise. They copy unintended source scenery, performers, or recordings in place of the instructed event, and video references amplify the habit: Wan3.0-Video’s usability-veto rate rises from 12.0% without a video reference to 55.9% with one, and it replays the reference speech in 9 of 78 speech instances.

Quick start
git clone https://github.com/Tencent-Hunyuan/ORAV-Bench.git
cd ORAV-Bench && pip install -e .

# timestamped visual panels and media proxies
orav prepare runs/example/manifest.json \
  --config examples/evaluation.json --output runs/example

# blind Listener + reference-aware AB/BA Judge
orav evaluate runs/example/manifest.json \
  --config examples/evaluation.json --output runs/example --workers 8

# Davidson–Bradley–Terry ranking, 95% bootstrap CIs
orav rank runs/example/comparisons.json \
  --output runs/example/ranking.json
